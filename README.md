# Никита & Ольга — паспорт семьи Анохиных

Сайт-приглашение на свадьбу 13 июня 2027 в стиле путешествий: обложка паспорта, программа «Рейс», виза-анкета для гостей.
Анкеты приходят в Telegram-чат организаторов через Cloudflare Worker.

## Структура

```
index.html        страница: «Паспорт семьи Анохиных»
css/style.css     стили
js/config.js      настройки: дата для отсчёта и адрес воркера
js/themes.js      варианты цветов сайта и палитры дресс-кода (кнопка с тремя полосками)
js/main.js        анимация обложки, появление блоков, обратный отсчёт
js/rsvp.js        анкета и «живая виза» с именем гостя
wedding.ics       событие для кнопки «Добавить в календарь»
assets/           фотографии (см. ниже)
worker/           Cloudflare Worker, который пересылает анкеты в Telegram
sw.js             удаляет старый service worker у гостей, которые открывали прошлую версию сайта
```

Сборка не нужна: это статический сайт. Подойдёт Netlify, Cloudflare Pages или GitHub Pages.
Для локального просмотра: `python3 -m http.server` в папке проекта и откройте http://localhost:8000.

## Анкеты в Telegram

Токен бота хранится только в секретах воркера, в коде сайта его нет.

1. **Бот.** Создайте бота у @BotFather (или используйте существующего) и скопируйте токен.
2. **Чат организаторов.** Создайте группу, добавьте в неё бота и организаторов, напишите в группу любое сообщение.
   Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":-100...}`. Это `CHAT_ID`.
   Несколько чатов можно указать через запятую.
3. **Воркер** (нужен Node.js):
   ```sh
   cd worker
   npx wrangler login
   npx wrangler secret put BOT_TOKEN
   npx wrangler secret put CHAT_ID
   npx wrangler deploy
   ```
   В `worker/wrangler.toml` указано имя уже существующего воркера `late-glitter-508d`, поэтому его старый код заменится новым, а адрес останется прежним.

   Без командной строки: в панели Cloudflare откройте воркер → **Edit code**, вставьте содержимое `worker/src/index.js` и нажмите **Deploy**.
   Затем в **Settings → Variables and Secrets** добавьте секреты `BOT_TOKEN` и `CHAT_ID`.
4. **Защита.** Когда у сайта появится адрес, впишите его в `ALLOWED_ORIGINS` в `worker/wrangler.toml` (или в переменные воркера в панели).
   Тогда воркер будет принимать анкеты только с вашего сайта.
5. Если адрес воркера изменится, обновите `rsvpEndpoint` в `js/config.js`.

Проверка: отправьте анкету на сайте, и в чат придёт сообщение «✈️ Новая анкета гостя».
Если что-то не так, смотрите логи в панели Cloudflare (воркер → **Logs**).
