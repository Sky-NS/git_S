# ANOKHIN AIRWAYS — Moscow to Forever

## Премиальный свадебный сайт в стиле авиакомпании

Полноценное одностраничное приложение (SPA) для свадебного приглашения Никиты и Ольги Анохиных.

### Концепция

Гости ощущают себя пассажирами эксклюзивного рейса Moscow — Forever бизнес-классом.
Каждая деталь продумана как в премиальной авиакомпании: от посадочного талона до багажного ограничения.

### Технологии

- **HTML5** — семантическая разметка, доступность (ARIA)
- **CSS3** — кастомные свойства, Grid, Flexbox, анимации
- **Vanilla JavaScript** — модульная архитектура, без фреймворков
- **GSAP + ScrollTrigger** — продвинутые анимации и параллакс
- **Intersection Observer API** — производительный скролл-триггер
- **PWA** — Service Worker, манифест, offline-страница
- **SVG** — все иконки и иллюстрации в векторе

### Секции

1. **Hero** — кинематографическое открытие с ночным небом, звездами и самолетом
2. **Boarding Pass** — роскошный посадочный талон с перфорацией и QR-кодом
3. **Story** — редакционная секция с историей рейса
4. **Flight Route** — анимированная SVG траектория с движущимся самолетом
5. **Timeline** — расписание рейса от регистрации до приземления
6. **Venue** — место проведения с интерактивной картой и компасом
7. **Dress Code** — элегантная цветовая палитра
8. **Baggage** — багажное ограничение с юмором
9. **Countdown** — премиальный обратный отсчет
10. **RSVP** — форма регистрации с генерацией персонального посадочного талона
11. **Footer** — минималистичный подвал

### Интеграция Telegram Bot

В файле `js/rsvp.js` закомментирована функция отправки уведомлений в Telegram.
Для активации:

1. Создайте бота через @BotFather
2. Получите токен и chat_id
3. Раскомментируйте `TELEGRAM_CONFIG` и вызов `sendTelegramMessage`

### Запуск

Проект — статический сайт. Достаточно открыть `index.html` в браузере или развернуть на любом хостинге (Netlify, Vercel, GitHub Pages).
